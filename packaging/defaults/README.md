# Packaged defaults

System-wide defaults Tessel package ships. They apply to new users and to
anyone who never changed the setting; per-user choices made in Global Settings
(gsettings, `~/.config/gtk-*/settings.ini`, `~/.config/mimeapps.list`) win.

Paths below mirror the install root.

| Default | File | Notes |
|---|---|---|
| Icon theme Papirus-Dark | `usr/share/glib-2.0/schemas/90_tessel.gschema.override` | `org.gnome.desktop.interface icon-theme`; run `glib-compile-schemas` in `%posttrans`. Requires `papirus-icon-theme-dark` (a separate package from `papirus-icon-theme`). |
| Dark style | `usr/share/glib-2.0/schemas/90_tessel.gschema.override`, `etc/gtk-3.0/settings.ini`, `etc/gtk-4.0/settings.ini` | `org.gnome.desktop.interface color-scheme` is `prefer-dark`, the key Global Settings > Theme > Style changes, and `gtk-application-prefer-dark-theme=true` for programs that read only `settings.ini`. It is the same in every desktop layout: layouts do not change the style. |
| Default wallpaper | none here: the `tessel-wallpapers` package installs `usr/share/wallpapers/tessel/slate-*.png` from `branding/wallpaper/renders` | Built in (`crates/core/src/wallpaper.rs`): a screen with no entry in `~/.config/tessel/shell/wallpapers.json` shows the dark Slate render nearest its shape (16:9, 16:10 or 32:9), in every desktop layout. The desktop, both wallpaper settings pages, the dock's wallpaper colors and the lock screen's "desktop" background all use it. An entry, also one for a plain color, is a choice and wins. A `~/.local` install reads `~/.local/share/tessel/wallpapers/` (`tools/install.py --only wallpapers`). |
| Archive Manager opens archives | `usr/share/applications/labwc-mimeapps.list` | `[Default Applications]` for every archive mime type of `org.tessel.ArchiveManager.desktop` (its `MimeType=` line is the source; keep both in sync). Read for `XDG_CURRENT_DESKTOP=wlroots:labwc` sessions; requires the tessel-archive package (`/usr/local/share/applications/org.tessel.ArchiveManager.desktop` or the packaged path). Per-user: an existing `~/.config/mimeapps.list` keeps its choices (`tessel-migrate` renames the old ids). |
| Pictures opens images | `usr/share/applications/labwc-mimeapps.list` | `[Default Applications]` for every `image/*` type on the `MimeType=` line of `org.tessel.Pictures.desktop` (keep both in sync). Per-user choices in `~/.config/mimeapps.list` (Global Settings > Default Apps) still win. |
| Archive Manager settings | none shipped (built in) | Defaults live in code (`components/archive/settings/src/lib.rs`, `Settings::default`): info panel on, preserve paths on, extract into subfolder on, open destination off, close after extraction off, all plugins enabled, internal preview on, preview limit 50 MB. `~/.config/tessel/tessel-archive.json` is written only when the user changes a setting (Archive Manager or Global Settings > Archive Manager). |
| Icon theme Papirus-Dark (GTK fallback) | `etc/gtk-3.0/settings.ini`, `etc/gtk-4.0/settings.ini` | Read by GTK when no settings portal/gsettings value applies. |
| Login check of the icon theme | `etc/xdg/autostart/tessel-icon-theme.desktop` | Replaces a theme that is not installed, and KDE's default (Breeze) unless it was chosen in Global Settings, with the theme chosen in Global Settings (`~/.config/tessel/icon-theme`) or else Papirus-Dark. Runs `tessel-icon-theme` (tessel-session-startup crate; install it on `PATH`, e.g. `/usr/bin`) through `labwc-xdg-autostart.target`. |
| Snap layouts per screen | not shipped (`~/.config/tessel/snap-layouts.json`) | Set in Global Settings → Desktop Behavior. Absent means every screen snaps to halves. The file is the source for the `<!-- tessel snap layouts begin/end -->` block of `<region output="…">` elements in the user's rc.xml, which needs labwc 0.20.2-27 or later. |
| Pointer theme | not shipped (`~/.config/tessel/cursor-theme`) | Chosen in Global Settings → Theme. Also written to gsettings `cursor-theme`, `gtk-cursor-theme-name` in `~/.config/gtk-{3,4}.0/settings.ini`, `XCURSOR_THEME` in labwc's `environment` and `~/.local/share/icons/default/index.theme`. Without a choice the installed fallback (Adwaita) is used. |
| Fonts | not shipped | Global Settings → Theme writes gsettings `font-name`, `document-font-name`, `monospace-font-name`, `gtk-font-name` in `~/.config/gtk-{3,4}.0/settings.ini`, and the `<font place="ActiveWindow|InactiveWindow">` elements of rc.xml. Running GTK 4 applications get the gsettings values through the settings portal (xdg-desktop-portal-gtk, required by tessel-meta). `tessel-configure-session` keeps a title font that has a `<slant>` element and otherwise writes Sans 10 SemiBold. |
| Clipboard kept after apps close | `usr/lib/systemd/user-preset/90-tessel.preset` | `enable tessel-clipboard.service` (WantedBy=graphical-session.target). Package `components/clipboard/tessel-clipboard.service` into `usr/lib/systemd/user/` with `ExecStart=` pointing at the packaged `tessel-clipboard`, and run `systemctl --global preset tessel-clipboard.service` in `%post` (or use `%systemd_user_post`). Per-user equivalent: `tools/install.py --apply` then `systemctl --user enable --now tessel-clipboard.service`. |
| Clipboard settings | none shipped (built in) | Defaults live in code (`components/clipboard/settings/src/lib.rs`, `Settings::default`): keep the clipboard on, keep the middle-click selection off, skip password-manager secrets on, largest kept copy 64 MB. `~/.config/tessel/clipboard.json` is written only when the user changes a setting (Global Settings > Clipboard). |
| Saved passwords: tessel-keyring is the Secret Service | `usr/share/dbus-1/services/org.freedesktop.secrets.service`, `usr/lib/systemd/user/tessel-keyring.service` (sources: `components/keyring/data/`, with `ExecStart`/`Exec` pointing at the packaged `tessel-keyring`) | The package must replace gnome-keyring's activation file for `org.freedesktop.secrets` (Conflicts: gnome-keyring, or remove its `/usr/share/dbus-1/services/org.freedesktop.secrets.service` and `/usr/share/xdg-desktop-portal/portals/gnome-keyring.portal`; ship a `tessel-keyring.portal` with `DBusName=org.freedesktop.secrets`, `Interfaces=org.freedesktop.impl.portal.Secret`, `UseIn=labwc;wlroots`). Per-user equivalent: `tools/install.py --apply --only dbus` (user D-Bus service dir wins). |
| Saved passwords unlock with the login password | `etc/pam.d/tessel-login` (Tessel Login's login stack), `etc/pam.d/passwd` | `auth substack tessel-login-auth` + `-auth optional pam_tessel_keyring.so`, `-session optional pam_tessel_keyring.so` after `session include system-auth`, and `-password optional pam_tessel_keyring.so` in passwd. Ship `pam_tessel_keyring.so` in `/usr/lib64/security/` and the helper at `/usr/lib/tessel/tessel-keyring` (the module's `helper=` option; its default follows `TESSEL_PACKAGED`). Every entry point returns PAM_IGNORE. Per-user equivalent: `pkexec /usr/bin/python3 -I tools/install.py --system --apply --only keyring`. |
| Login screen configuration | `etc/greetd/tessel-config.toml`, `etc/tessel/login/`, `usr/lib/systemd/system/tessel-login.service` | Tessel's own greetd configuration (greetd's `config.toml` is not changed), appearance and the greeter's labwc files. The package enables the unit on first install, unless another display manager is enabled. |
| Login screen background | `etc/tessel/login/appearance.json` (`picture`) | The dark Slate wallpaper, the desktop's default: `/usr/share/wallpapers/tessel/slate-3840x2160.png` from `tessel-wallpapers`, which `tessel-login` requires. The greeter shows each screen the render nearest its shape (16:9, 16:10 or 32:9), as the desktop does. Same value built in (`crates/locking/src/login_model.rs`, `Appearance::default`) for a missing file. Always the `/usr/share` path: the greeter's own user cannot read a home folder. |
| Login and lock PAM stacks | `etc/pam.d/tessel-login-auth`, `etc/pam.d/tessel-lock`, `etc/pam.d/tessel-lock-password`, `etc/pam.d/tessel-lock-fingerprint`, `etc/security/tessel-login-faillock.conf` | Lock and login share `tessel-login-auth`, which includes `system-auth` live, and one failed-attempt policy. |
| Screen-share picker | `etc/xdg/xdg-desktop-portal-wlr/labwc`, `etc/xdg/xdg-desktop-portal-wlr/wlroots` | Points xdg-desktop-portal-wlr at the packaged `tessel-capture-picker`. A user's `~/.config/xdg-desktop-portal-wlr` wins. |
| Secret Service portal | `usr/share/xdg-desktop-portal/portals/tessel-keyring.portal` | Serves `org.freedesktop.impl.portal.Secret` from tessel-keyring. |
| New user labwc configuration | `labwc/rc.xml`, `labwc/menu.xml` | Built into `tessel-configure-session`, which writes them when a user has none, with `@BIN@` and `@SHELL_BIN@` set for the install type. Holds what the session does not manage: Alt+Tab, Super, screenshot keys, prompts, mouse bindings, workspaces and menus. Existing files are not replaced. |
| Adaptive Sync is Automatic (fullscreen only), per screen | built in (`components/displays/src/daemon/layout.rs`, `vrr_mode`); `etc/tessel/displays/cfg.yaml` lists no screen | A screen's mode is stored in `~/.config/tessel/displays/cfg.yaml` (or the packaged `etc/tessel/displays/cfg.yaml`): in `VRR_OFF` is Off, in `VRR_ALWAYS` is Always, in neither (the default) is Automatic, which turns adaptive sync on only while an app is fullscreen on that screen. `tessel-displays --daemon` writes every connected screen's mode into the running labwc's `rc.xml` (`<adaptiveSyncOutputs>` block, `fullscreen`/`yes`/`no`) and runs `labwc --reconfigure`, so labwc's global `<core><adaptiveSync>` does not matter. Saved setups that listed a screen in neither list (formerly always on) become Automatic. Changed in Global Settings > Displays > Adaptive Sync (VRR). |
| New users start on the Tessel layout | `components/settings/desktop/layouts/tessel.layout`, `labwc/rc.xml` | `ConfigStore::default()` in the dock uses it when `~/.config/tessel/dock/config.json` is missing. For a user with no `rc.xml`, `tessel-configure-session` writes the layout's window gap (`<gap>10</gap>` in the default `rc.xml`, and `~/.config/tessel/tiling/config.json`) and its clock (`~/.config/tessel/clock.json`). Existing settings are not changed. |
| Media in the panel is off by default | built in (`components/dock/src/core/config.rs`, `GROUPS_OFF_BY_DEFAULT`), every `components/settings/desktop/layouts/*.layout` (`"media": false`) | The panel does not show the media player and the dock does not follow media players until the user turns on Global Settings > Dock/Panel > Visible groups > Media (also in Dock Settings). Turning it on or off takes effect at once, without restarting the dock. A saved `~/.config/tessel/dock/config.json` that already says `"media": true` keeps it on. The Media window (`tessel-media`), the lock screen's media controls and the media keys are not affected. |
| System tray icons are Medium by default | built in (`components/dock/src/core/config.rs`, `DEFAULT_TRAY_ICON_SIZE`; sizes in `components/dock/src/ui/indicators.rs`, `system_tray_layout`) | The panel's system tray (its status icons, the tray applications and More apps) is drawn larger than before: 28 px at the default 40 px icon size and 21 px in the Tessel layout's compact bar, instead of 20–22 px and 12–16 px. Large is bigger again; Small is the old size. The tray never makes the panel thicker. Users choose in Global Settings > Dock/Panel > System tray > System tray icon size (also in Dock Settings); the change takes effect at once, without restarting the dock. A `~/.config/tessel/dock/config.json` saved before the setting existed gets Medium; the layouts do not set it, so applying one keeps the user's choice. |
| One system tray, expanded only by More apps | built in (`components/dock/src/core/config.rs` `GROUPS`, `components/dock/src/core/group_layout.rs`), every `components/settings/desktop/layouts/*.layout` | Tray applications and the built-in applets are one panel group, "System tray" (id `service_apps`), with the More apps button last. Collapsed it shows the always-shown tray applications and the always-visible applets; More apps (click, or Enter from the keyboard) shows the rest. It never expands on hover and never collapses on a timer; a click outside, Esc, a second click or a menu from it closing collapses it. A saved `~/.config/tessel/dock/config.json` or layout that still names the old `system_tray` group loads: the tray stays where the applets were and is shown if either group was shown. The next save writes only `service_apps`. |
| Win and Mac layouts: one workspace, no indicator | `components/settings/desktop/layouts/win.layout`, `components/settings/desktop/layouts/mac.layout` | Applying either layout sets one workspace (`<desktops number="1">` in `rc.xml`) and hides the panel's workspace indicator, as Windows and macOS start out. The indicator keeps its place in the panel order, so turning Workspaces back on puts it where it was. Users already on Win or Mac keep their settings until they apply the layout again. |
| Display defaults | `etc/tessel/displays/cfg.yaml` | Turns automatic scale on, and is read before the old `/etc/way-displays/cfg.yaml` and its sample entries. Replaced by a user's own `~/.config/tessel/displays/cfg.yaml` or `~/.config/way-displays/cfg.yaml`. |
| Automatic display scale | built in (`components/displays/src/daemon/layout.rs`) | With `AUTO_SCALE_DPI: 96`, screens under 20 inches aim for 135 dpi and larger ones for 110 dpi, up to 2.5 unless `AUTO_SCALE_MAX` says otherwise. Any other `AUTO_SCALE_DPI` is used as given. |

Session startup also checks the icon theme at login. A theme that is not installed is replaced, so
removing a theme package never leaves the desktop without icons. So is KDE's default (Breeze), which
KDE writes into the shared GTK settings at every Plasma login and which lacks many of Tessel's icons,
unless it was chosen in Global Settings. The replacement is the theme chosen in Global Settings, else
Papirus-Dark.

When adding a new suite-wide default, add its file here and a row to this table.
