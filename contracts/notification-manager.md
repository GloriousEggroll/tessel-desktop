## 2. D-Bus (session bus)

Name `org.freedesktop.Notifications`, path `/org/freedesktop/Notifications`, two interfaces on that path (notification_service.py:9-45).

**Ownership** (notification_service.py:58-67): raw `RequestName(name, flags=4 /*DO_NOT_QUEUE*/)`; result ≠ 1 → `RuntimeError("Another notification server is already running")` → daemon prints and exits 1. Never ALLOW_REPLACEMENT/REPLACE_EXISTING. On close: unregister then `ReleaseName`.

### `org.freedesktop.Notifications` (spec 1.2)
| Member | Signature | Behaviour |
|---|---|---|
| `GetCapabilities` | `() → as` | `["actions","body","icon-static","persistence"]` (no body-markup, hyperlinks, images, sounds) |
| `GetServerInformation` | `() → ssss` | `("Waydock Notifications","Waydock","1.0","1.2")` |
| `Notify` | `(susssasa{sv}i) → u` | model.notify(…, sender=caller unique name) |
| `CloseNotification` | `(u) → ()` | close reason 3; unknown/inactive id → error `org.freedesktop.Notifications.InvalidId` "Notification does not exist" |
| signal `NotificationClosed` | `(uu)` | **unicast** to the original sender (destination = sender of Notify; broadcast if unknown) (notification_service.py:105-109) |
| signal `ActionInvoked` | `(us)` | unicast to original sender (notification_service.py:111-114) |

No `ActivationToken` signal.

### `org.waydock.Notifications1` (custom control API)
| Member | Signature | Behaviour |
|---|---|---|
| `GetState` | `() → s` | JSON of `model.state()` (compact separators `,`/`:`, ensure_ascii=False) |
| `SetSettings` | `(s) → ()` | JSON patch; >16384 chars → InvalidArgs; validation errors → InvalidArgs |
| `ClearHistory` | `()` | clear all, active ones close reason 2 |
| `MarkRead` | `()` | |
| `Dismiss` | `(u)` | active → close(2); inactive → delete from history |
| `ClearApp` | `(s)` | key len >256 → InvalidArgs |
| `Activate` | `(us)` | invoke action on active item |
| `ShowCenter` | `()` | toggle history popup at (`bottom`, 76) |
| `ShowCenterAt` | `(su)` | edge ∈ top/bottom/left/right, 0≤offset≤4096 else error; toggle |
| `ShowSettings` | `()` | open settings window |
| signal `StateChanged` | `(s)` | broadcast full state JSON on every model change kind (notify/close/settings/history/read/presentation) |

Errors: ValueError/TypeError/OverflowError → `org.freedesktop.DBus.Error.InvalidArgs`; other → `org.freedesktop.DBus.Error.Failed` (notification_service.py:160-163).

### Client protocol (notification_client.py)
- Proxy flags DO_NOT_AUTO_START|DO_NOT_LOAD_PROPERTIES; calls NO_AUTO_START, 5 s timeout. Tracks `g-name-owner`: owner lost → `state={}`, `ready=False`, error `"Notifications are not running in this session."`; owner gained → GetState. Serial guard drops replies from previous owner. `call` returns False when no owner. `request()` = sync CLI helper, 3 s.

### D-Bus consumed
- None at runtime except the session bus itself. Compositor info via `waydock-toplevel` helper (§6).

## 3. Model semantics (notification_model.py) — the core parity surface

- IDs: uint32, never 0, wrap at 0xffffffff, skip in-use (:155-160). `next_id` persisted.
- `notify` (:162-209): app_name empty → `"Application"`; text fields strip NUL; limits: summary 4096, body 16384, app_name/icon/image_path 4096, desktop-entry/category/stack-tag 256, sender 256, output 128.
  - Replacement: `replaces_id` of an **active** item keeps id and resets timer; unknown/expired → new id.
  - Stack tag hint `x-dunst-stack-tag` or `x-canonical-private-synchronous`: replaces an active item with same tag **and** same app_name **and** same desktop_entry.
  - urgency hint (any int; clamped 0..2, default 1). Bool/non-int ignored.
  - timeout: `-1` → urgency 2 ? 0 (persistent) : `timeout_ms` setting; `0` → persistent; else ms (max 0x7fffffff).
  - actions: pairs from flat `as`, at most 16 pairs (index < min(len-1, 32)), key ≤256, label ≤1024, empty/duplicate keys dropped.
  - image: `image-data` | `image_data` (iiibiiay), else `image-path`|`image_path`; `icon_data` only if neither. Validation (:89-115): 0<w,h≤2048, bits=8, channels = 4 if alpha else 3, stride ≥ w·ch, stride·h ≤ 2 MiB, last row may omit padding; stored base64 of `(h-1)*stride + w*ch` bytes.
  - `value` hint → progress 0..100 (non-int → 0); `transient`, `resident` booleans (True or int 1); `x-waydock-output` (connector), `x-waydock-workspace` (bool).
- `close(id, reason)` (:211-226): reasons 1 expired, 2 dismissed, 3 recalled (CloseNotification), 4 capacity eviction. Reason 2 marks read. Transient items deleted on close. Closed signal emitted after invalidation (before the change event).
- `activate` only for keys offered on active items; emits ActionInvoked, then closes(2) unless `resident` (resident → marked read only).
- Hover: `set_hovered` pauses remaining deadline; resume restores remaining.
- Trim (:355-374): newest first by (timestamp, id); >100 active → oldest closed reason 4; inactive non-transient beyond `history_limit` deleted; aggregate image base64 > 8 MiB → older images dropped.
- `clear_history` emits one closed per active item + exactly one `history` change; `clear_app(key)` same for one app key; `app_key = desktop_entry || app_name || "Application"`.
- `state()` (:376-383): `{settings, notifications[newest first, without deadline/sender/hover_remaining], unread (non-read, non-transient), storage_error, presentation{fullscreen,checking}, ready:true, error:""}`. Each notification: `id, app_name, summary, body, icon, image_path, image, actions[[k,l]], urgency, progress|null, timestamp (epoch float), active, read, transient, resident, desktop_entry, category, stack_tag, output, workspace, expire_timeout` (+`close_reason` once closed).
- **Text is plain**: UI uses set_text, never markup.

### Settings (DEFAULT_SETTINGS :14-23; validation :321-342)
| Key | Type / range | Default |
|---|---|---|
| `do_not_disturb` | bool | false |
| `dnd_until` | number, finite, 0 ≤ x < 2^40 (epoch s; 0 = indefinite) | 0 |
| `suppress_fullscreen` | bool | true |
| `timeout_ms` | int 1000..60000 | 6000 |
| `history_limit` | int 1..500 | 100 |
| `muted_apps` | list ≤500 unique non-empty str ≤256, no NUL | [] |
Unknown keys reject the whole patch atomically. Patch with `do_not_disturb` but no `dnd_until` forces `dnd_until=0`. `dnd_deadline('hour')=now+3600`, `'tomorrow'` = next day 08:00 local, `'off'`=0.

## 7. Presentation policy (notification_manager.py)
- `suppressed = dnd_active || (suppress_fullscreen && guard.blocked)`; `may_present = !muted && (urgency==2 || !suppressed)`.
- New notify: if center visible → mark all read, no toast; muted → never toast; else pending + `presentation_hold` + `guard.refresh(force=True)`; pending→eligible only after the check finishes (`checking==false`).
- Any focus-signature change hides all stacks immediately while re-checking (if suppress_fullscreen).
- `drop_suppressed`: on settings/history change and when suppressed — suppressed ids are removed from pending/eligible → **no backlog replay** after DND/fullscreen ends.
- Blocked fullscreen destroys an open center.
- Unknown window state (backend not ready) counts as blocked.
- Toast monitor: focused (activated, not minimized) window's output else first monitor; `x-waydock-output` picks that connector; `x-waydock-workspace` uses the "workspace" monitor (bottom/right edge → leftmost/lowest; else rightmost/top) (notification_placement.py:5-26).
- No polling: one GLib timeout for the next expiry (`ceil(ms)+1`), one for timed DND (capped 60 s, re-armed to survive suspend). Idle = only 2 unix-signal sources (SIGINT/SIGTERM → quit).
- Show center clears pending/eligible (hides toasts) and marks read; ShowCenter* toggles (second call closes). Show settings closes center.

## 10. Memory / startup
- Daemon imports GTK4, Gtk4LayerShell, GdkPixbuf, Pango, ThreadPoolExecutor (1 worker) + spawns `waydock-toplevel`; ~32 MB RSS today. Lazy: NotificationCenter/Settings only on demand; `notification_placement` imported in render path.
- Separate long-lived `notification_status.py` (GLib/Gio only) per waydock instance — candidate to fold into a Rust binary flag (`--status-stream`) but path `notification-manager/notification_status.py` is hard-coded in waydock/status_backend.py:30 (keep a shim or change waydock in the same swap).
- Startup must own the bus name synchronously before readiness; `--check` must answer within 3 s.
