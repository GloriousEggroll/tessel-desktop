# tessel-brightness — external contract

Source: `~/tessel-bluetooth/tessel-brightness/` (refs `file:line`, relative to that dir unless prefixed).
Role: single resident owner of monitor hardware brightness/contrast (DDC/CI + logind backlight),
per-monitor scaling (proxy to way-displays IPC), optional auto-dim (own swayidle child), keyboard
brightness OSD, and the dock "Displays" popup. Live RSS ≈ 47 MB (largest wave-1/2 service).

## 3. IPC

### 3.1 D-Bus owned (session bus)
- Name `org.tessel.BrightnessManager` (via GApplication), object `/org/tessel/BrightnessManager`, interface `org.tessel.BrightnessManager.Controls` (`brightness_client.py:5-21`), registered on the GApplication connection (`brightness_manager.py:74-76`). Also the standard `org.gtk.Application` / `org.freedesktop.Application` objects of GApplication (used for command-line forwarding).

| Member | Signature | Semantics (`brightness_manager.py:147-181`) |
|---|---|---|
| `GetState()` | `→ s` | JSON of `state()` (`:135-145`). Allowed while closing |
| `Refresh()` | `→ b` | backend.refresh() (full re-probe) + scaling.refresh(); true |
| `SetValue(s connector, s feature, d value, s expected_id)` | `→ b` | feature ∈ {brightness, contrast}, value 0–100; counts as activity; cancels keyboard burst; `core.set_value` (restores dim first) |
| `SetAutoDim(b)` | `→ b` | = SetSettings(current ∪ {auto_dim}) |
| `SetSettings(s json)` | `→ b` | JSON object with exactly keys auto_dim/dim_after/dim_percent; persists, restores dim, updates swayidle |
| `SetScale(s connector, d scale, s expected_id)` | `→ b` | expected_id = `scale_id`; scale 1.0–2.5 snapped to 0.125 |
| `SetAutoScale(b)` | `→ b` | way-displays AUTO_SCALE |
| signal `Changed(s json)` | | emitted from `_changed()` only when the JSON differs from last emission (`:183-199`); re-entrancy coalesced via idle |

Errors: `org.tessel.BrightnessManager.Controls.Error` with message (ValueError/TypeError/OSError). While closing every method but GetState fails with tr("Brightness controls are restarting. Try again shortly."). Unknown method ⇒ tr("Unknown brightness command.").

**State JSON** (GetState / Changed / basis of `--check`):
```json
{"ready": true, "busy": false, "dimmed": false, "error": "",
 "settings": {"auto_dim": false, "dim_after": 120, "dim_percent": 30},
 "scaling": {"ready": true, "busy": false, "error": "", "auto_scale": false},
 "displays": [{
   "connector": "DP-2", "name": "<wlr-randr description>", "id": "<sha256(EDID)>[:connector if duplicated]",
   "enabled": true, "method": "ddc|backlight|unsupported", "error": "", "geometry": [x,y,w,h]|null,
   "diagnostic": "<optional ddcutil stderr>",
   "brightness": {"supported": true|false|null, "value": 75.0, "raw": 75, "max": 100, "busy": false, "error": "", "diagnostic": "?"},
   "contrast":   {…same…},
   "scale_id": "<sha256(json[NAME,DESCRIPTION,MAKE,MODEL,SERIAL_NUMBER])>|''",
   "scale": {"supported": true, "value": 1.25, "busy": false, "override": true, "error": ""}}]}
```
- `ready` = idle controller exists and (hardware backend ready OR scaling ready) (`:136-137`).
- `supported:null` = not yet probed ("Loading display controls…" in UI). Displays only known to way-displays get `id="scale:"+scale_id`, `method:"unsupported"` (`display_scaling.py:112-135`).
- `id` for unmatched outputs: `"unidentified:"+connector` (`brightness_backend.py:315`).

### 3.3 `brightness_client.py` — shared client protocol (keep as a Python file until tessel-displays is ported)
- `BrightnessClient(on_changed, refresh_on_connect=False)`; `Gio.DBusProxy` with `DO_NOT_AUTO_START|DO_NOT_LOAD_PROPERTIES`; watches `g-name-owner`; on owner ⇒ `GetState` (+ `Refresh` if refresh_on_connect). Methods: `set_value(connector, feature, value, expected_id=None)` (defaults to state's `id`), `set_auto_dim(b)`, `set_scale(connector, value, expected_id=None)` (defaults to `scale_id`), `set_auto_scale(b)`, `set_settings(dict)`, `refresh()`, `close()`. Call timeout 15000 ms. Initial state `{"ready":False,"displays":[],"settings":{auto_dim:False,dim_after:120,dim_percent:30}}`. Client-side `busy` = server busy OR pending settings calls. Unowned ⇒ error "Brightness controls are unavailable." (untranslated). A `False` reply sets error to scaling error / state error / "The change could not be applied."
- **Consumers**: `way-displays/tessel-displays:741-758` loads it **by file path** (`../tessel-brightness/brightness_client.py` or `~/.config/waybar/scripts/tessel-brightness/brightness_client.py`) via importlib and constructs `BrightnessClient(cb, refresh_on_connect=True)` (TypeError fallback to 1-arg); Global Settings → Displays embeds tessel-displays window (`tessel-settings/desktop_pages.py:130-174,256,268`); `brightness_status.py`.

### 3.4 Unix sockets / signals / other
- way-displays IPC socket: `$XDG_RUNTIME_DIR/way-displays.sock`, else `way-displays.$XDG_VTNR.sock` if it exists (`display_scaling.py:26-32`). Protocol: send `OP: <GET|CFG_SET|CFG_DEL|CFG_WRITE>\n` + optional YAML `CFG: {...}`; read until EOF (5 s deadline, 16 MiB cap); YAML reply must have `DONE: true`, int `RC`; RC≠0 ⇒ error from `MESSAGES` (≤500 chars) (`:35-64`).
  - SetScale: GET, verify target, `CFG_SET {SCALE: {<DESCRIPTION>: value}}`, `CFG_WRITE`, GET (`:202-229`).
  - SetAutoScale(false): `CFG_SET {AUTO_SCALE: false}` then `CFG_DEL {SCALE: {desc: value or 1.0 for attached heads}}`, `CFG_WRITE`.
  - CFG_WRITE failure ⇒ "Scaling changed, but the display settings could not be saved: …".
  - Poll: GET every 5 s (`:159`) — the only background polling.
- SIGTERM/SIGINT (`GLib.unix_signal_add`): `_stop` ⇒ cancel keys/OSD, close idle listener, `core.restore_all(done=quit)` (`brightness_manager.py:96-97,314-324`).
- No lock files beyond GApplication name ownership.

## 5. Auto-dim (`brightness_idle.py`)
- Disabled by default; no swayidle needed when off.
- When on: spawns (Popen, stdin/stdout devnull, close_fds) — note: sh-string commands:
  `swayidle -w -C /dev/null timeout <dim_after> '<py> <dir>/brightness_manager.py --idle-dim <TOKEN>' resume '<…> --idle-restore <TOKEN> </dev/null >/dev/null 2>&1 &' before-sleep '<same restore>' after-resume '<same restore>'` (`:75-95`). `<py>`=`sys.executable`, args `shlex.join`-quoted. Restore commands are detached (`&`) to avoid deadlock while swayidle runs resume on termination.
- TOKEN = `secrets.token_urlsafe(24)`, regenerated on every policy change; compared with `compare_digest`; stale tokens ignored (`:97-103`).
- Child polled every 1 s; unexpected exit ⇒ error "Automatic dimming stopped unexpectedly (exit status N)." + restore_all; no auto-restart (`:116-136`). Terminate → wait 1 s → kill; if stop unconfirmed, keep ownership and never spawn a second listener (`:138-158`).
- Unchanged (enabled,delay) ⇒ child kept (idle clock not reset) (`:55-59`).
- Dim flow (`brightness_manager.py:216-224`): valid token ⇒ `guard.idle_inhibited(cb)`; if not inhibited and activity counter unchanged ⇒ `core.dim()`. Every 5 s while dimmed, if inhibited ⇒ restore (`:226-237`).
- Core dim (`brightness_core.py:119-164`): for each enabled display with brightness supported: fresh `read_feature`; target = `max(1, round(max*dim_percent/100))`; skip if target ≥ raw (never brightens); journal durably **before** `set_raw(target, expected_raw=raw)`.
- Restore (`:166-217`): for each journal entry with matching id+connector: read; if `max` changed ⇒ pending error; if `raw != target` (someone changed it) ⇒ forget without writing; else `set_raw(raw, expected_raw=target)`. Failures ⇒ "Brightness restoration is pending: …", retry after 30 s. Disconnected monitors wait until they reappear.
- Independent from tessel-power's own `dim` idle action (power_dim.DimOverlay overlay, `tessel-power/power_manager.py:115-121,306-323`) — both may run.

## 6. Hardware backend (`brightness_backend.py`)
- One daemon worker thread `display-hardware`, serial queue; results via `GLib.idle_add`.
- Discovery: `wlr-randr --json` (timeout 4 s, env `LC_ALL=C`) + sysfs DRM matching by connector name (must be unique & `connected`) (`:296-345`). Internal = `^(eDP|LVDS|DSI)-` ⇒ backlight (if found), else DDC. DDC bus: the unique `i2c-N` child of the connector dir (DP AUX) preferred over `ddc` symlink; multiple ⇒ error (`:252-267`). `ddcutil` absent ⇒ "Hardware monitor controls require ddcutil."
- Duplicate EDID hashes ⇒ id suffixed `:connector` (`:339-344`).
- Logical geometry from current mode / scale, swapped for 90/270 transforms, `int(w/scale)` (`:64-78`).
- Probe: `ddcutil --noconfig --bus N getvcp 10 12 --terse` (timeout 6 s); parse only continuous `VCP xx C raw max` with 0<max≤65535 (`:44-55,362-375`). Backlight contrast unsupported: "Internal display contrast is not exposed by its backlight."
- Write: re-discover, validate identity (connector,id,path,method,bus,backlight,enabled) + EDID bytes + bus, read current, compare `expected_raw` (mismatch ⇒ "The monitor setting changed externally; no hardware value was written."), revalidate, then `ddcutil --noconfig --bus N setvcp <10|12> <raw> --noverify` or logind SetBrightness; read back up to 3× (sleep 0.15·n); mismatch ⇒ "The display reported X after requesting Y." (`:561-612`). Percent→raw: `floor(v*max/100+0.5)`.
- Probing policy: once at start; on GDK monitor `items-changed` / `notify::geometry` / `notify::scale-factor` ⇒ 750 ms settled non-full refresh (wlr-randr only; re-probe only connectors whose identity changed) (`:139-170,405-441`); full refresh on popup open / `Refresh`. DDC displays whose probe failed are remembered in `_no_ddc` and not re-probed until unplugged (avoids syslog flood).
- Failed discovery ⇒ all displays `enabled=false` with error (stale controls disabled) (`:448-458`).
- `close()` fails all pending callbacks once: "Display controls were closed before the request completed."

## 7. Keyboard brightness (`brightness_keys.py`, OSD = shared `adjustment_osd.py`)
- Lazily created on first `--brightness-*` (`brightness_manager.py:245-256`): `AdjustmentOSD(app)` (layer-shell, namespace `desktop-adjustment-osd`, keyboard mode NONE, 1500 ms), `BrightnessKeys(core, osd)`.
- Monitor: `osd.resolve_monitor(cb)` (OSD shows tr("Adjusting brightness…") meanwhile). Selection (`:20-59`): exact geometry match ⇒ that display (or None if unsupported); else unique x,y match (fractional rounding); else connector == `monitor.get_model()`; else palette.json geometry match; else single internal backlight; else single supported display; else None (ambiguous externals untouched).
- Burst: steps accumulate during resolution; then `core.restore_all(done=…)` (auto-dim restored before relative step), desired = current% + Σsteps clamped 0–100; one write in flight, only latest target sent next; equal ⇒ no write. Slider `SetValue` cancels the burst.
- OSD `show("brightness", value|None, monitor=, detail=)`; detail strings here are **English literals** (not tr'd): "Adjusting <name>", "This display is no longer connected.", "Brightness is unavailable for this display.", "Choose a display in Brightness settings.", "No display supports hardware brightness control.", "Display controls are not ready.", "The display could not be adjusted."/"restored."

## 12. Memory / startup
- Imports GTK4 + gtk4-layer-shell (tray_popup at popup time), **PyYAML**, threading, plus full `PowerBackend` (UPower/PPD/logind subscriptions) just for the inhibitor guard; two worker threads; a `BrightnessClient` proxy to itself. Popup/UI/OSD modules imported lazily.
- Startup cost dominated by wlr-randr + one ddcutil getvcp per DDC monitor (seconds per monitor; off main thread). Rust port: async subprocess or worker thread, guard = minimal logind `ListInhibitors` + `GetSession`/`Active` calls (no PPD), avoid self-proxy.
- `brightness_status.py` is a separate Python process per dock (≈15–20 MB); Rust should provide the same stream binary/CLI path or tessel-dock must switch to D-Bus directly.
