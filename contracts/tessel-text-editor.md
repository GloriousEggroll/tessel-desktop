# tessel-text-editor (Text Editor) — external contract

Source: `~/tessel-bluetooth/tessel-text-editor` (`text_editor.py` 45 LOC launcher, `editor_ui.py` 1185, `document.py` 317,
`recovery.py` 90, `org.tessel.TextEditor.desktop`; tests `test_document.py`, `test_editor_ui.py`).
A standalone GTK4 + GtkSourceView 5 editor, one document per window, no tabs, no service, no autostart.

### CLI (argparse, prog = `text_editor.py`)
`usage: text_editor.py [-h] [--check] [files ...]` — description `Edit text files in separate windows.`
- `files` (`*`): paths or GIO URIs (`sftp://`, `smb://` …) — passed as `[argv0, *files]` to `Application.run`.
- `--check`: print `json.dumps(dependencies())` and exit 0/1 without a window:
  `{"ready": true, "gtk": 4, "gtksourceview": 5, "tabs": false}` or `{"ready": false, "error": "<msg>", "dependency": "gtksourceview5"}`.
  The check `CDLL("libgtk4-layer-shell.so", RTLD_GLOBAL)`, `gi.require_version("GtkSource","5")`, imports companion_theme.
- Dependency failure without `--check`: stderr `Text Editor requires GTK4 and GtkSourceView 5: <error>`, exit 1.
- Unknown option → argparse usage + `text_editor.py: error: unrecognized arguments: …`, exit 2; `-h/--help`; unique prefixes (`--ch`) accepted; `--` ends options.

## 3. Document semantics (document.py)
- `location(value)`: `Gio.File` as is; `Path` → `new_for_path`; str → `new_for_commandline_arg(expanduser(str))`; local path `.absolute()` or None.
- `ENCODINGS = utf-8, utf-8-sig, utf-16-le, utf-16-be, utf-32-le, utf-32-be, windows-1252, iso-8859-1, shift_jis, gb18030, big5, koi8-r`; names normalised by `codecs.lookup(..).name` (`windows-1252`→`cp1252`, `iso-8859-1`→`iso8859-1`). `NEWLINES = LF CRLF CR`.
- `decode(data, encoding)`: >64 MiB → ValueError; BOM detection order UTF-32LE, UTF-32BE, UTF-8, UTF-16LE, UTF-16BE (only if no encoding requested or it matches; `utf-8-sig` accepts the UTF-8 BOM); default utf-8; **strict** decode (UnicodeDecodeError → UI asks for an encoding, never replacement characters); NUL → ValueError "This file contains binary data and cannot be edited safely as text."; dominant ending = max of CRLF/CR/LF counts (ties: CRLF, CR, LF), `mixed` if >1 kind; text normalised to `\n`.
- `encode`: unchanged text+encoding+newline returns the original bytes (mixed endings/BOM byte-identical); else newline translation + strict encode (UnicodeEncodeError text shown, file untouched); same encoding keeps its BOM; switching to utf-16/32-le/be adds that BOM.
- Local `save`: resolves symlinks (target replaced, link kept); if saving to the loaded file or its name and `changed_on_disk()` (resolved target moved, size or SHA-256 differs) → `ConflictError("The file changed outside Text Editor. Reload it or save your changes as another file.")`; existing other file without overwrite → `FileExistsError("The selected file already exists.")`; >64 MiB / NUL → ValueError; existing → `replace_contents(data, etag, make_backup=False)` (mode kept); new → temp + `link()` (EEXIST raised: never replaces a racing writer; other link errors → exclusive `Gio.File.create`). A deleted loaded file is a conflict (not recreated).
- GIO (`save_gio`, remote documents): etag-guarded `replace_contents` (WRONG_ETAG → ConflictError); without etags size + digest; missing → conflict; new → exclusive `create` (EXISTS → FileExistsError).
- `name`, `folder` (parent's parse name), `identifier` (path or URI), `same_location` (resolved path or `Gio.File.equal`).
- Error texts are the Python exception strings (OSError `[Errno N] …: 'path'`, `GLib.Error` `g-io-error-quark: … (N)`), untranslated.

## 5. Subtle behaviours
- **Busy guard**: file operations run on a per-window single worker thread; while busy the view is read-only and `open save save-as reload preferences paste replace print` (and undo/redo/cut) are disabled; a second operation is ignored. Results are dropped once the window is closing.
- **Unsaved guard** (`guard`): open, reload, Open Recent, Vim `:e`, closing the window → "Save changes?"; Save runs the action only after a successful save; a failed save keeps the edits and shows the banner.
- **External changes**: local files watch the parent directory (events for the path or its rename target), remote files `monitor_file`; 300 ms debounce, `changed_on_disk()` on the worker, banner with Reload unless busy/closing/the document or its etag changed meanwhile. Remote documents are re-checked when the window becomes active (≥5 s apart).
- `modified` = buffer modified or encoding/newline changed (`format_modified`); saving clears modified only if the buffer text did not change during the save.
- set_document: irreversible text load, cursor at start, language guessed from the name, bookmarks dropped, previous draft discarded, banner hidden, file watched, recent updated.
- Drafts: written 30 s after edits; on window destroy without the guard (app quit/session end) the draft is written synchronously and kept; finish_close/discard removes it. First window (or the active one) offers pending drafts once per process; Restore puts each draft in its own window (an untouched untitled window is reused) over its original file (loaded with the draft's encoding; a missing file becomes a named unsaved document), keeping the draft id so saving removes it; Discard deletes them.
- Vim commands (`execute-command`, leading `:` stripped): `w`/`write [path]`, `wq`/`x [path]` (close only after a successful save), `q`/`quit` (guarded close), `q!`/`quit!` (close unless busy), `e`/`edit [path]` (guarded load, or named new document), else not handled.
- Drop of files opens them through `Application.open` (separate windows).
- Each window removes its CSS provider, file monitor, timers and Vim client on destroy.
